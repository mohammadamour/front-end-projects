# Front-End Projects Archive

Welcome to my front-end archive! I'm [@mohammadamour](https://github.com/mohammadamour).

## 📖 Overview

This repository is a collection of front-end projects I originally built as a teenager between the ages of 16 and 17. Most of these projects were built using pure HTML, CSS, and vanilla JavaScript—with no frameworks or heavy libraries. They were based on various designs I found online, serving as practice grounds to hone my raw front-end coding skills.

I am currently working my way through these older projects to **refactor and modernize them**. The goal is to eliminate old technical debt (like bloated CSS or outdated DOM manipulation), improve accessibility, implement responsive design best practices, and bring them up to modern 2024 web standards.

---

## 📂 Featured Projects

### 1. [Network Landing Page](./Network%20landing%20page)
**Briefing:** A complex, 8-section agency landing page built from scratch. Originally weighed down by over 2,000 lines of CSS and hard-coded desktop widths, it has been completely modernized into a professional, mobile-first portfolio piece.
- **Features:** Fluid typography (`clamp()`), Native `IntersectionObserver` scroll animations, glassmorphism UI elements, animated JS counters, and fully semantic/accessible HTML.
- **Sections:** Hero, Partners, Features, Services, Stats, Certifications, Portfolio, Testimonials, FAQ, Footer.
